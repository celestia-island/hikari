# إضافة بلاطة

HkAddTile هي البلاطة المنقّطة القياسية لدعوة إلى إجراء: الحالة الفارغة
للقائمة، صف «إضافة واحد آخر» في نهاية القائمة، ومنطقة اختيار ملف أو
إفلاتها. تشريح واحد وثلاث صيغ معتمدة.

## الاستخدام الأساسي

```hikari:tsx
<HkAddTile onClick={openAdd}>لا مصادر بعد — أضف واحداً للبدء</HkAddTile>
```

وقت تشغيل Vue يأتي أولاً؛ نظير Rust يتبع عندما يستهلكه مضيف Rust.

## الصيغ

- الافتراضية — كتلة عمودية في الوسط (الأيقونة فوق النص): الحالة الفارغة
  لقائمة أو لوحة.
- `compact` — صف رفيع أفقي («＋ إضافة واحد آخر») يقع في
  نهاية قائمة الصفوف بدلاً من زر منفصل تحته.
- `droppable` — أي صيغة تقبل إضافة سحب الملفات. حالة السحب تعيد استخدام
  لغة طبقات السحب الموجودة (تنقيط باللون الأساسي على أرضية باهتة).
  الإفلات يُصدر `drop-files` فقط إذا حمل ملفاً واحداً على الأقل — النص
  وروابط URL يتجاهلان، فيستطيع المضيف الاعتماد على الحمولة.

## API

| Property | Description | Type | Default |
|----------|-------------|------|---------|
| disabled | تعطيل النقر ورفض السحب | boolean | false |
| droppable | قبول سحب الملفات (الإفلات غير الفارغ فقط) | boolean | false |
| compact | صيغة الصف الرفيع في نهاية القائمة | boolean | false |
| icon | مكوّن الأيقونة (نمط lucide) | Component | Plus |

| Slot | Description |
|------|-------------|
| default | نص التسمية |
| icon | استبدال الرمز الافتراضي |

| Event | Description |
|-------|-------------|
| click | تفعيل البلاطة (MouseEvent أصلي) |
| drop-files | إفلات يحمل ملفاً واحداً على الأقل — `(files: File[], event: DragEvent)` |
