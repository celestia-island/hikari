# Static Asset Mounting Examples

The `hikari-render-service` crate — and the `HikariRenderServicePlugin` API these examples
were written against — has been retired. Static-asset mounting now belongs to the tairitsu
framework (`tairitsu-packager` / `tairitsu-ssr`), which hosts `hikari-components`; see
<https://github.com/celestia-island/tairitsu> for the current API.

This page is kept as a pointer so existing links keep resolving; the examples were removed
because the crate they imported no longer exists.
