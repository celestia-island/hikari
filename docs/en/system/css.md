# CSS Utilities

Tailwind-compatible utility classes for rapid styling.

## Display

Control element display behavior.

```hikari:rust
rsx! {
    div { style: "padding:1rem;color:#999;", "Component preview: pages/system/css#display" }
}
```
```hikari:tsx
<div style="display:flex;gap:8px"><div style="padding:1rem;background:#e8edf3;border-radius:4px;color:#333">Flex 1</div><div style="padding:1rem;background:#e8edf3;border-radius:4px;color:#333">Flex 2</div></div>
```
