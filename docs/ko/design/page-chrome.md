# 페이지 크롬: 액션 바 문법

관리자 및 콘솔 페이지는 하나의 헤더 계약을 공유합니다. 페이지는 용도를 선언하는 슬롯을 통해
오른쪽 위 액션 클러스터를 소유하며, 페이지의 주요 진입점은 페이지 본문이 아니라 클러스터
안에 삽니다.

## 정규 슬롯

모든 등록은 용도를 선언합니다. 클러스터는 뷰가 등록한 순서와 무관하게 정규 슬롯을 고정
순위로 렌더링합니다:

```text
[생성][필터][검색][새로 고침][창]
```

정규 슬롯에 해당하지 않는 용도의 등록은 커스텀입니다. 정규 구역 뒤에 등록의 역순으로
오른쪽에서 왼쪽으로 채워지며, 정규 구역은 절대 밀리지 않습니다.

## 생성 규칙

페이지의 주 생성 액션——새로운 최상위 개체(공급자, 채널, 그룹, 접근 규칙, 공유 테마 라인의
테마)를 만드는 진입점——은 **오른쪽 위 클러스터의 플러스 아이콘 버튼, 새로 고침의 왼쪽**입니다.
페이지 본문 안의 독립 버튼이어서는 안 됩니다.

본문 버튼에 인쇄되었을 라벨은 그 버튼의 접근 가능한 이름과 툴팁이 됩니다. 생성 대화상자의
소유권은 페이지에 남습니다.

**문맥 안의 추가는 면제됩니다.** 편집기·대화상자·마법사·카드 안의 하위 목록에 행을 추가하는
플러스("모델 행 추가", "구성원 추가", "마운트 방식 추가")는 그 지역 문법의 일부이지 페이지의
생성 액션이 아니므로 제자리에 남습니다.

## 지오메트리

클러스터는 한 줄의 크롬입니다. 모든 아이콘 버튼은 같은 크기 사다리(`useChromeActionSize`)를
걷고 글리프는 16px입니다. 고정 크기 버튼이 사다리 크기의 이웃 사이에 끼면 다른 패밀리의
버튼으로 읽힙니다. 클러스터는 공유 헬퍼로 조립하고 손으로 박은 크기는 금지입니다.

## 참조 구현

크롬은 hikari가 제공합니다: `HkAdminHeader`의 액션 행, `HkIconButton`,
`useChromeActionSize`. 호스트는 위 슬롯을 렌더링하는 액션 바 컨텍스트로 등록합니다. chest
webui의 `useActionBar` / `usePageCreateAction`이 이 문법의 참조 구현입니다.
