# Add Tile

HkAddTile — стандартная пунктирная плитка-приглашение к действию: пустое
состояние списка, строка «добавить ещё» в конце списка и зона выбора /
перетаскивания файлов. Одна анатомия, три канонические формы.

## Базовое использование

```hikari:tsx
<HkAddTile onClick={openAdd}>Источников пока нет — добавьте первый</HkAddTile>
```

Сначала реализуется среда исполнения Vue; зеркальная реализация Rust
появится, когда плитку начнёт использовать Rust-хост.

## Формы

- по умолчанию — центрированный вертикальный блок (иконка над подписью):
  пустое состояние списка или панели.
- `compact` — тонкая горизонтальная строка («＋ добавить ещё») в конце
  списка строк вместо отдельной кнопки под списком.
- `droppable` — любая форма дополнительно принимает перетаскивание
  файлов. Состояние перетаскивания повторяет язык существующих
  drag-оверлеев (пунктир основным цветом на бледном фоне). `drop-files`
  срабатывает только при переносе хотя бы одного файла — текст и URL
  игнорируются, поэтому хост может полагаться на полезную нагрузку.

## API

| Property | Description | Type | Default |
|----------|-------------|------|---------|
| disabled | Отключает нажатие и отклоняет перетаскивание | boolean | false |
| droppable | Принимает перетаскивание файлов (только непустой drop) | boolean | false |
| compact | Тонкая строка в конце списка | boolean | false |
| icon | Компонент иконки (стиль lucide) | Component | Plus |

| Slot | Description |
|------|-------------|
| default | Текст подписи |
| icon | Замена стандартной иконки |

| Event | Description |
|-------|-------------|
| click | Активация плитки (нативный MouseEvent) |
| drop-files | Перенос с ≥1 файлом — `(files: File[], event: DragEvent)` |
