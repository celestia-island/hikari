# i18n 國際化

Hikari 的國際化系統支援多語言切換。

## 支援語言

| 語言 | 代碼 | 方向 |
|------|------|------|
| 英語 | `en-US` | LTR |
| 簡體中文 | `zh-Hans` | LTR |
| 繁體中文 | `zh-Hant` | LTR |
| 法語 | `fr-FR` | LTR |
| 德語 | `de-DE` | LTR |
| 俄語 | `ru-RU` | LTR |
| 西班牙語 | `es-ES` | LTR |
| 葡萄牙語 | `pt-BR` | LTR |
| 阿拉伯語 | `ar-SA` | **RTL** |
| 日語 | `ja-JP` | LTR |
| 韓語 | `ko-KR` | LTR |

## 基礎用法

```hikari
rsx! {
    div { style: "padding:1rem;color:#999;", "Component preview: pages/system/i18n#basic" }
}
```

## 語言切換

```hikari
rsx! {
    div { style: "padding:1rem;color:#999;", "Component preview: pages/system/i18n#switch" }
}
```

## API

| 屬性 | 說明 | 類型 | 預設值 |
|------|------|------|--------|
| language | 目前語言 | Language | English |
| toml_content | 翻譯內容 | &str | - |
